# 花名册示例（全部为虚构人物）

> 这份花名册配合 `examples/exports/` 里的虚构导出表使用，演示脚本的全部判定情况。
> 人名一律用代号 A001、A002…；自己用时，换成你们群成员的会议昵称或规范名。
> 用法：把它复制成 `roster.md` 再修改。
> 花名册是唯一基准：有人加入、退出、改昵称时，先改这里，再统计。

## 一、规则

| 项目 | 值 |
|---|---|
| 名称 | 晨读打卡（示例） |
| 准时线 | 06:00:00 |
| 缺勤线 | 07:00:00 |
| 统计日 | 周一至周五 |
| 每周免罚请假 | 1 |

- **准时线**：首次入会时间 ≤ 准时线，算准时。06:00:00 算准时，06:00:01 就算迟到。
- **缺勤线**：首次入会晚于缺勤线，算缺勤。写「无」表示不设缺勤线，再晚也只算迟到。
- **统计日**：不在统计日的导出也会出日报，但会标注「仅供参考」；周报不计入。
- **每周免罚请假**：每周前 N 次请假不计，超出的次数在周报里按迟到计。
- 命令行参数（如 `--on-time 20:00`）优先于这张表。

## 三、名字映射（腾讯会议显示名 → 规范名）

会议昵称和规范名不一样时，在这里登记，多个变体用 `/` 分隔。

下面三种情况脚本会自动处理，不用登记：
- 昵称和规范名完全相同。
- 只多了括号后缀，比如「A004(三组)」「A003（上海）」。
- 只是英文大小写不同，比如「a007」。

| 腾讯会议显示名（变体用 / 分隔） | 规范名 | 备注 |
|---|---|---|
| A006-平板 | A006 | |
| A008-手机 | A008 | |
| A012家长 | A012 | 家长代入会 |
| A015-广州 | A015 | 会议里也写成小写 a015-广州 |
| A018的iPad | A018 | 第二台设备 |
| A019 | A019 | 已退出 |
| A020 | A020 | 整期请假 |

备注里写了「退出」「请假」「排除」的人，参会时只记录，不计入统计。
