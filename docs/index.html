腾讯会议考勤统计 Skill

把腾讯会议导出的「成员参会概况」表交给 AI，或者自己跑一行命令，就能拿到准时、迟到、缺勤、请假名单，再加一份周报。昵称五花八门也能对上人。

查看源码 30 秒试跑

能做什么

📅 日报

准时（按入会时间排序）、迟到、缺勤、请假、无法匹配的昵称，最后一行汇总。

🗓 周报

每人每天的状态矩阵，外加需关注名单、缺勤名单、全勤名单。

🔤 昵称对得上

括号后缀、英文大小写、手机和平板双设备、家长代入会，都能自动认到同一个人。

⚙️ 规则可配置

准时线、缺勤线、统计日、每周免罚请假次数，写在花名册里或用参数改。

git clone https://github.com/zj85997-hash/tencent-meeting-attendance-skill.git
cd tencent-meeting-attendance-skill
python3 scripts/attendance_stat.py examples/exports/*.xlsx \
  --roster examples/roster.example.md --leave-file examples/leaves.example.csv --out out
  1. 腾讯会议 → 历史会议 → 导出「成员参会概况」
  2. 把 examples/roster.example.md 复制成 roster.md，填上你们的成员和规则
  3. 运行脚本，或者把文件夹装进 Claude Code / WorkBuddy，对 AI 说「统计今天的考勤」
